# Money Plan

固定費・サブスク・クレジットカード・欲しい物をまとめて、「いつまでに・どの口座に・いくら入れておけばいいか」がわかるスマホ向けのお金管理アプリです。

**アプリを開く** → https://kanameyamamoto.github.io/money-plan/

## できること

- **ホーム**：今月・来月に必要なお金、月の稼ぐ目標との差、カードの請求額、口座ごとの入金スケジュール、現金払いと積立
- **カレンダー**：日ごとに、どの口座からいくら引き落とされるかを表示。カードの支払額調整の期限や、欲しい物を買う期限も表示
- **支払い**：固定費とサブスクを1つの一覧で管理。毎月・毎年・数か月ごとに対応し、支払い方法（銀行口座・クレジットカード・現金）を選べる
- **欲しい物**：値段と買う期限から、毎月いくら積み立てればいいかを計算
- **口座**：銀行口座・クレジットカード・証券口座を登録。カードは引き落とし日・引き落とし口座・支払額調整期限日を設定し、毎月の請求額をまとめて入力できる

## 使い方（iPhone）

1. Safariで上のURLを開く
2. 共有ボタンから「ホーム画面に追加」を選ぶ
3. ホーム画面のアイコンから開く

## データについて

- 入力したデータは、使っている端末のブラウザの中だけに保存されます。サーバーには送られません
- 別の端末とは同期されません
- Safariで開いただけの場合、しばらく使わないとデータが消えることがあります。ホーム画面に追加して使ってください
- 「口座」タブの一番下の「書き出す」でデータをコピーしてバックアップできます。「読み込む」に貼り付けると元に戻せます

## 構成

`index.html` 1ファイルで動きます。ビルドやインストールは不要です。
